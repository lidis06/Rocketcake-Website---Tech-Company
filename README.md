# Rocketcake-Website-Tech-Company

In my website development part of my course in year 13 I was tasked with creating a website in which encompases all the necessary details and features a running website needs in order to be successful and this website showcases them skills with my HTML skills and how i started out coding for web development. 

HotBeans – Web Development Company Website

Project Type: Web Development / Website Design
Development Tool: RocketCake Website Builder
Technologies: HTML, CSS, JavaScript, PHP
Project Category: Early Web Development Portfolio Project

Project Overview

HotBeans is a multi-page website project created using RocketCake, designed around a fictional web development company.

The website presents information about the company, its services, employees, location, and opportunities for individuals interested in pursuing careers in web development.

The primary objective of this project was to gain practical experience in website design, page structure, navigation, and the integration of different web technologies.

This project forms part of my programming portfolio and demonstrates my early experience with web development before progressing towards more advanced computer science and cybersecurity-related projects.

Website Features

1. Homepage

The homepage introduces HotBeans and provides an overview of the company's services.

Key features include:

Company branding and introductory content.

Navigation links to other website pages.

Service sections covering development, planning, and support.

Contact buttons directing visitors to further information.

Company location and office information.

Integration of external website components using Elfsight.

2. About Us Page

The About page provides background information about the fictional company and its employees.

Features include:

Company background and organisational information.

Employee profiles and descriptions of their responsibilities.

Information about workplace culture and teamwork.

Images and visual elements supporting the website's presentation.

3. Contact Page

The Contact page provides visitors with information about the company's location and how to get in touch.

Features include:

Office location information.

Company contact details.

Map imagery.

Navigation to a separate location page.

Integration of an external Elfsight component.

4. Courses Page

The Courses page introduces visitors to external educational resources related to web development.

Features include:

Information about web development training.

External links to educational providers.

Supporting images and descriptive content.

This section was designed to encourage individuals interested in web development to explore opportunities for improving their technical knowledge.

5. Application Page

The website includes an application-related PHP page intended to process submitted information.

The PHP code demonstrates introductory server-side programming concepts, including:

Accessing submitted form data through $_POST.

Iterating through submitted values using a foreach loop.

Constructing a text-based representation of the submitted information.

Using PHP's mail() function to attempt to send the information to a designated email address.

Implementation limitation: The original project was developed using the free edition of RocketCake, which restricted certain website components. Consequently, the application functionality should be considered a prototype rather than a complete, production-ready recruitment system.
